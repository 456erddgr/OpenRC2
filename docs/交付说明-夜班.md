## 二、RC2「拨一会儿就卡住重连」处理

1. 抓包确认：服务端心跳 0 条；客户端自驱 12 字节心跳；发/不发都会在 3~6 秒被 RST（`re/now.pcap`、三组 A/B）。
2. `nc` 对照 + 杀 `dji.go.v6` + 读端饥饿探针，逐一排除「格式错 / 抢名额 / 读得慢」。
3. **缓解方案（1.27.0 起）**：双源摇杆——TCP 9Hz 优先，超过 220ms 没帧就用 DJI protocol binder（≈6Hz）补帧。实测 `drops=5 fills=3`，空档被填满，用户侧不再感到卡住。
4. RST 本身未根除（协议层订阅细节），已在 README「已知限制」如实记录。
