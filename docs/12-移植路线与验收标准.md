# 12 · 原生移植路线与验收标准（Lead 定的规矩）

> 目标：把 EdgeTX 2.12.2 的**真源码**跑到 RC2 上，界面是原版 colorlcd 那一套，而不是"照着画的复刻"。
> 本文定路线、定边界、定验收口径。任何一条要改，先改这里再改代码。

## 1. 路线：不用 EdgeTX 的 superbuild，用我们自己的构建描述

EdgeTX 的 cmake 是给"固件 + 桌面模拟器（SDL）"写的，含 `ExternalProject`、`FetchContent(gtest/imgui)`、
`find_package(Qt6)` 等与 Android 无关的东西。**改造成本 > 收益**。

我们的做法：
- 自己写 `CMakeLists.txt`（或直接给 clang++ 一份文件清单），只编需要的模块：
  - `radio/src/gui/colorlcd/**`、`radio/src/libopenui/**` —— 界面层（原版界面的本体）
  - `radio/src/storage/yaml/**` + EEPROM 模拟 —— 配置读写
  - `radio/src/mixer*.cpp`、`mixes.cpp` —— 混控核心
  - `radio/src/translations/**`、字库 —— 文案与字形
  - **我们自己的 HAL 层**（抄 `radio/src/targets/simu/` 的桩，把 SDL 换成 LVGL flush，键盘换成 `etx_touch`）
- 好处：编不过时错误精确到"缺哪个符号"，而不是被 ExternalProject 搅成一团。

## 2. 工具链与硬约束（不可协商）

| 项 | 值 | 原因 |
| --- | --- | --- |
| ABI | **armeabi-v7a（32 位）** | 本 ROM 对新装 App 强制 `abiOverride=armeabi-v7a`，只有 arm64 装不上（`docs/09`） |
| NDK | r26d（26.3.11579264） | 已验证可编出可加载 so |
| 链接 | `-shared -fPIC -static-libstdc++ -llog` | 否则 dlopen 缺 `libc++_shared.so` / `__android_log_print` |
| API | 29 | `minSdk=29 targetSdk=29`（≥30 会被 DJI ReviewPermissionsActivity 劫持） |
| 线程 | **禁止在 C 侧起线程** | 全部由 Java UI 线程调用（100Hz `etx_tick`、≤30fps `etx_render`） |
| LVGL | 8.2，钉 `5f129c540ec43a4e5aebff9f77b3688b57a78063` | EdgeTX 自己用的分支 `release/v8.2`，不许用分支头 |
| LVGL 配置 | `LV_COLOR_DEPTH 32`、`LV_MEM_SIZE 64*1024`、`LV_TICK_CUSTOM 0`、`LV_USE_OS LV_OS_NONE`、关 `LV_USE_FS_*` | 时间由 `etx_tick(ms)` 传入；存储我们自己管；不许开线程/FS |

## 3. 桥接契约（`docs/07` 为准）

10 个 C 符号：`etx_init/etx_shutdown/etx_version/etx_screen_w/etx_screen_h/etx_set_inputs/etx_tick/etx_touch/etx_channels_us/etx_render`。
输入是**原始 11bit ADC（0..2047）**，顺序 `{RH,RV,LV,LH}`（MCU 物理序），校准由核心按 `radio.yml` 的 mid/spanNeg/spanPos 自己做。
渲染 ARGB_8888 int。

## 5. 改动纪律

- 改 `vendor/edgetx/**` 任何一行，必须登记到 `docs/01-工具链炸点.md` 的改动表（文件:行 + 原因 + 原文对照），
  以便上游升级时重放。
- 已知必改一处：`cmake/GenericDefinitions.cmake:60` 的 `cmake_path(NATIVE_PATH Python3_EXECUTABLE ...)`
  在中文用户名路径下让 cmake 静默崩溃（退出码 127），改成 `set(PYTHON_EXECUTABLE "${Python3_EXECUTABLE}")`。
- 源码拉取：`codeload` 的 tar.gz 直连约 28 KB/s，整包 30–40 分钟；逐目录 `sparse-checkout add` 每目录 1–5 分钟且易 `invalid index-pack output`，
  所以**整包一次拉完**，不要逐目录抠。

## 6. 现在还差什么（诚实清单）

- LVGL 尚未上屏（K3 未过），所以"原版界面"还没出现在设备上；当前屏幕是调试三屏。
- 32 位 + 174MB 内存约束下，LVGL 静态池 64KB 是否够用尚未实测；不够就报数字再议。
- 音频、SD 卡热插拔、USB 串口（ELRS TX 模块）都还没接；ELRS 出口方案见 `docs/11`。
- USB 主机模式未实测（等用户拔线），见 `lab/03-host切换实测.md`。
