## 三、发射通路（三条原始设想逐条判定）

| 设想 | 判定 | 依据 |
|---|---|---|
| 机身自带射频跑 ELRS | ❌ 不可行 | DJI 私有 SDR（dji_sdrs_agent/O3-O4），定制 ASIC 不是可重编程 SX1280 |
| ELRS 接收机刷成高频头 | ❌ 不可行 | TX 固件是 **LR1121**、RX 固件是 **SX128X**；bootloader md5 相同但**引脚表六线全错位**、功率脚不同 → 能刷能启动、发不出射频 |
| USB 四芯直焊 TX/RX | ❌ 电气错误 | D+/D- 是 480Mbps 差分对，不是 3.3V UART |
| **UDP/WiFi → ESP32 → CRSF → ELRS TX 模块** | ✅ **今天就能用** | APK 侧 UDP 已实测；ESP32 桥固件已写好（`lab/firmware/`，未上机验证） |

采购清单：ELRS TX 模块 ¥150–250、ESP32-S3 ¥25–60、1S 电池 ¥20、线材 ¥10。

## 四、还缺什么
