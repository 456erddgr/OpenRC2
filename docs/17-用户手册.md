# RC2 EdgeTX · 用户手册（2026-11-01）

面向使用者，不是开发者。技术细节在 `docs/07`（桥接接口）与 `docs/08`（版本与回归）。

## 一、装
```
adb install -r dist/RC2ETX-1.10.5.apk
```
或把 APK 拷到 SD 卡用文件管理器安装（需允许"安装未知来源"）。

**必须先做一件事：关掉大疆那个模拟飞行软件（com.fly.simulator）。**
它会占住 DJI 内部 40007 端口的唯一客户端名额，我们 App 就每 ~25 秒被踢一次，表现为"摇杆老是断连"。

## 二、两种界面
- **普通模式**：顶部有页签条，下面是 8 个页签（原版 / 原生 / 触摸 / 通道 / 混控 / 输出 / 校准 / 诊断）。
- **全屏模式**：整个屏幕都是原版 EdgeTX 界面，右上角有「退出全屏」。
  ```
  adb shell am start -n com.rc2.etx/.MainActivity --es action full --ei on 1
  ```

## 三、怎么操作原版界面
底部那排八个键就是**给你用手指点的**，对应真机遥控器上的物理键：

| 屏幕键 | 真机键 | 作用 |
|---|---|---|
| ↑ ↓ ← → | 方向键 | 移动焦点 / 改数值 |
| ENT | 确认 | 进入选中项 / 确认对话框 |
| RTN | 返回 | 退出当前页 |
| PG↑ / PG↓ | 翻页 | 切换顶部页签 |

- **点行 = 选中它**（不直接进入）。进入要再按 ENT。
- **拖动 = 滚动**。模型设置页往上拖，能看到"计时器 1/2/3、初始检查、微调、油门"。
- **旋钮**（如果接了外接手柄）一格 1%。
- EdgeTX 自己的顶栏（电压/模型名/时间那条）**不响应点击**，这是原版行为，不是 bug。

## 四、物理摇杆
- 开机自动连上 DJI 内部接口，**不需要校准**。
- 映射已锁定 **AETR**：右横=副翼、右纵=升降、左纵=油门、左横=方向。
- 满行程 172..1811（对应 -100%..+100%）。
- 速率约 **24Hz**。DJI 内部推送上限，穿越机特技级延迟做不到。

## 五、看通道
「通道」页有 16 行：通道号、当前 us 值、百分比、条形图，底部是最新的 CRSF 帧 hex。
油门（CH3）在最左摇杆推上时是 1811、回到最低是 172。

## 六、输出
「输出」页四选一：空输出 / UDP / USB串口 / 录帧。
- **UDP**（推荐先用这个）：填电脑 IP:8888，PC 端跑 `python scripts/udp_listen.py 8888`。
  实测 75–83 Hz、0 坏包、16 通道解码正确。
- **USB串口**：接 ESP32-S3 之类的 CDC 设备，波特率 420000，输出 CRSF。
- 接线图见 `docs/05-ESP32-UDP转CRSF桥.md` 与 `docs/11-ELRS出口最终方案.md`。

## 七、改混控
两处都能改：
- App 侧「混控」页：每通道选源、expo/rate/offset、反向，保存后写 `model.json`。
- **原版界面**里改：模型设置 → 混控，改完存盘直接写回 SD 卡的 `model1.yml`（和真机 EdgeTX 一样）。

⚠️ **别用 root 覆盖 SD 里的文件**（除非覆盖后立刻 `chown -R 10038:10038`），
否则 App 写不进去，**改值存盘会静默失败**——界面看不出任何异常。

## 八、遇到问题
| 现象 | 原因 | 怎么办 |
|---|---|---|
| 摇杆全 0 / 断连 | 大疆模拟器占端口 | 关掉它 |
| 触摸"没反应" | 这台 ROM 吞掉 adb 注入 | 用真手指，或用 `--es action touch` 钩子 |
| 改值存盘没反应 | SD 文件属主变成 root | `chown -R 10038:10038` |
| 界面卡 | 旧版（1.10.4 之前） | 装 1.10.5 |
| logcat 里 `Fatal signal 6 (adbd)` | 这台 ROM 的 adbd 自己 abort | 不是我们 App 崩，忽略 |
