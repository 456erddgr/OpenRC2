2. 提供**完整对应源码**（或仓库链接 + 对应 commit）；
3. 不得删改版权声明；
4. 不得加"禁止逆向/禁止再分发"之类的额外限制。

## 与你设备相关的风险（再强调一次）

- 需要 root + 解锁 BL ⇒ **保修没了**；
- App 会用 root 改 USB gadget、改文件权限 ⇒ 时序出错**可能内核重启**；
- 解锁/改机可能**丢出厂射频校准**，这部分作者无法帮你恢复。
