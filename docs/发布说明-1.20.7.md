# OpenRC2 1.20.7 发布说明

## 这一版做了什么

### 1. USB 选择弹窗：重做 + 恢复

- **自绘深色卡片**，不再用系统白底列表：琥珀/蓝/橙三色左边条区分「游戏手柄 / 文件存储 / 串口」，每项带一句说明。
- **修掉"弹窗不见了"**：此前只在 USB `0→1` 广播时弹，线一直插着就永远等不到。现在启动后 1.5 秒弹一次（只要插着线），20 秒自动关闭。
- 通过 adb 钩子启动时**不弹**，避免挡住自动化验证。

### 2. USB HID 手柄：修掉"能识别但不走数据"

两个真因，都在 App 侧：

- `/dev/hidg0` 每次 gadget 重建后权限掉成 `600 root`，App（uid 10038）写不进去 → 打开失败时自动 `chmod 666` 再试。
- `hidOn` 没持久化，App 重启后没人往节点写报文 → 现在只要节点存在就自动续开。

设备实测：`reports=1811`，四轴满量程（`y=11[1..1013] z=1013[1..1023] rz=709[1..1023]`）。

### 3. 电脑端脚本：修掉"adb 启用不了手柄"

本 ROM 的 `su` 不在 PATH（`/debug_ramdisk/su`），原来的 `adb shell su -c` 必然失败。两个 `.bat` 已改为先试 `/debug_ramdisk/su`、失败再退回 `su`，并用 `state=configured` 判定成功。

### 4. 原生核心：换 Lua + CROSSFIRE 版

- `libetx.so` 6,724,516 B / sha256 `4f4817a0…`，含 Lua 5.3（621 个 Lua 符号）与 CRSF Lua API。
- About 页 OPTS 已见 `lua`。
- **已知问题**：菜单里按 `ENT` 仍会偶发崩（`lv_table_set_row_cnt+132`），定性为 `menu.cpp` 先 `deleteLater()` 后 `onPress()` 的 UAF，等 `table.cpp` 空指针补丁的 so。

### 5. 其他

- 新增 adb 钩子 `--es action rotary --ei n 3`（正数顺时针、负数逆时针），用于命令行验页内滚动/改值。
- 「复位」键移到「退出全屏」下方，不再压 EdgeTX 顶栏日期。

## 升级方式

```
adb install -r dist/RC2ETX-1.20.7.apk
```
